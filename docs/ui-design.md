# UI 设计规范（第 3 阶段 GUI）

本文档是第 3 阶段（桌面 GUI）的界面设计基线。风格定位：**简洁、有质感、高效**，
参考豆包客户端的设计气质——大留白、克制的用色、清晰的层级、无装饰噪音。

## 1. 设计原则

| 原则 | 说明 |
| --- | --- |
| 简洁 | 一屏只表达一件事；不堆信息、不加装饰性元素 |
| 有质感 | 细边框、柔和阴影、克制的圆角与留白，视觉干净不廉价 |
| 高效 | 常用操作 1~2 步可达：解锁 → 选凭据 → 复制密码；键盘可达 |
| 可信 | 安全类界面克制、清晰：错误不泄露细节、敏感信息默认隐藏 |

## 2. 设计 Token

### 2.1 颜色

| Token | 色值 | 用途 |
| --- | --- | --- |
| `primary` | `#4E85F0` | 主按钮、选中态、链接（浅一档，避免突兀） |
| `primary-hover` | `#3B72DD` | 主按钮悬停 |
| `primary-weak` | `#EEF3FE` | 选中列表项底色、弱强调背景 |
| `bg-page` | `#F6F7F9` | 窗口/页面背景 |
| `bg-card` | `#FFFFFF` | 卡片、面板、弹窗 |
| `border` | `#E5E8EC` | 卡片/输入框边框（1px） |
| `text-primary` | `#1F2329` | 主文字 |
| `text-secondary` | `#646A73` | 次文字（说明、标签） |
| `text-weak` | `#9AA1AB` | 弱文字（时间、提示） |
| `danger` | `#D83931` | 错误提示（极少使用） |
| `success` | `#2E8B57` | 成功反馈（极少使用） |

对比度：主文字与背景 ≥ 7:1，次文字 ≥ 4.5:1，弱文字仅用于非关键信息。

### 2.2 字号与字重

| 场景 | 字号 | 字重 |
| --- | --- | --- |
| 页面标题 | 18px | 600 |
| 详情标题（凭据名） | 16px | 600 |
| 正文 / 列表项 | 14px | 400 |
| 辅助说明 / 标签 | 12px | 400 |
| 密码显示 | 14px | 500（等宽字体 `Cascadia Mono`） |

### 2.3 圆角 / 间距 / 阴影

| 项 | 值 |
| --- | --- |
| 圆角：控件 | 8px |
| 圆角：卡片 / 面板 | 12px |
| 圆角：弹窗 / 大卡片 | 16px |
| 间距基准 | 4px 网格；卡片内 16px，页面 24px |
| 阴影（卡片） | `0 1px 2px rgba(31,35,41,0.04)` |
| 阴影（弹窗） | `0 8px 32px rgba(31,35,41,0.14)` |
| 边框 | 1px `#E5E8EC`，不用重阴影 |

## 3. 界面结构与流程

```
启动 ──▶ 解锁屏（输入主密码）
            │ 解锁成功
            ▼
        主界面：左侧凭据列表 + 右侧详情
            │ 点［＋ 添加］
            ▼
        添加凭据弹窗（标题 / 账号 / 密码）
```

### 3.1 解锁屏

- 居中卡片（约 340px 宽）：产品标识（蓝底圆角方形 + 应用名）+ 主密码输入框 + 解锁按钮。
- 输入框右置「显示 / 隐藏」切换；解锁按钮为主色、贯穿全宽。
- 底部一行弱文字提示，不暴露技术细节。
- 错误反馈：不区分「密码错误 / 文件损坏」，统一温和提示（与 CLI 一致的安全口径）。

### 3.2 主界面

- **左侧栏（约 220px）**：顶部［＋ 新建凭据］主色按钮；下方凭据列表
  （每项 = 圆形首字母图标 + 标题 + 账号小字；选中项 `primary-weak` 底色）；
  底部固定［锁定］［设置］。
- **右侧内容区**：选中凭据详情卡片——标题、账号、密码（默认圆点隐藏，
  「显示 / 隐藏」与「复制密码」按钮）、创建时间。
- **顶部**：搜索框（按标题/账号过滤）+ 备份入口（第 4 阶段启用）。

### 3.3 添加凭据弹窗

- 居中弹窗（约 380px）：标题、账号、密码三个输入框；底部右对齐［取消］［保存］。
- 保存前校验：三项均非空（与 storage.Entry 校验一致），主密码强度提示不在此重复。

## 4. 安全与合规的界面要求

- 密码默认隐藏，点击才露出；复制密码后 30 秒清空剪贴板（第 4 阶段），界面明示该行为。
- 锁定按钮即刻清空内存密钥与明文并回到解锁屏（第 4 阶段）；空闲自动锁定默认 5 分钟。
- 任何错误提示不输出内部细节（算法名、异常原文），符合等保「不泄露实现细节」的审计口径。
- 界面元素不出现密钥、盐、迭代次数等内部参数；密文不预览。
- 深色模式与无障碍（高对比、键盘焦点环）列入第 4 阶段增量项，不阻塞第 3 阶段交付。

## 5. 技术实现约定（Wails v2）

- 前端：纯 HTML/CSS/原生 JS，无框架依赖（减小体积、可控渲染）；设计 token 落为 CSS 变量。
- 字体：系统中文字体（`Microsoft YaHei` / `PingFang SC`），密码字段 `Cascadia Mono`。
- 图标：内联 SVG 图标集（锁、眼睛、加号、搜索、设置、备份），不引入图标库。
- 布局：单窗口固定最小尺寸（约 900×600），内容区弹性布局，禁止横向滚动。
