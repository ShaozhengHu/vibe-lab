# 验收清单

本清单用于两类场景：**日常改动验收**（每次合入前必须通过）与 **合规自检**
（第 5 阶段逐项核对，对应等保控制点与商用密码应用要求）。

## 1. 日常改动验收（每次合入前）

- [ ] `go build ./...` 编译通过，无警告
- [ ] `go test ./...` 全部测试通过
- [ ] 提交信息符合约定格式（`<类型>: <简述>`）
- [ ] 相关文档（README / docs）已同步更新
- [ ] 改动范围与提交描述一致，无夹带无关修改
- [ ] 真实凭据数据未进入版本库（`.vault` / 备份文件被 .gitignore 排除）

## 2. 加密核心专项验收（第 2 阶段起）

- [x] SM3 / SM4 通过国标测试向量（GB/T 32905 / 32907 标准示例，SM2 签名留待后续阶段）
- [x] SM4-GCM 加解密往返测试通过（密钥、IV 由随机数生成）
- [x] 密文被篡改（改 1 字节）时解密失败并返回明确错误
- [x] AAD 绑定元数据：修改条目 ID 后校验失败
- [x] KDF：相同主密码 + 相同盐得到相同密钥；盐不同则密钥不同
- [x] KDF 单次派生耗时处于 0.1~0.5 秒量级（实测 0.20s，AMD Ryzen 7 PRO 8845HS，迭代 60 万次）
- [x] 主密码错误时解锁失败，且不会泄露任何凭据内容
- [x] 失败次数达到阈值后触发锁定/退避（对应等保"登录失败处理"，第 4 阶段实现）

## 2.5 第 3 阶段（GUI）专项验收

- [x] 三屏可用：创建/解锁屏、主界面（左侧列表 + 右侧详情）、添加凭据弹窗
- [x] 界面样式依据 `docs/ui-design.md`（简洁质感、主色 `#4E85F0`、中文文案）
- [x] 密码默认隐藏，点击「显示 / 隐藏」才露出
- [x] 复制密码后 30 秒自动清空剪贴板
- [x] 锁定立即清空内存中的密钥与明文缓存
- [x] 错误提示不泄露实现细节（统一「主密码错误，或库文件已损坏」口径）
- [x] GUI 启动冒烟通过（窗口进程稳定运行不崩溃）；前端 JS 语法检查通过

## 3. 等保 / 密评自检（第 5 阶段逐项核对）

### 身份鉴别
- [x] 主密码复杂度校验（≥12 位，且大写/小写/数字/符号至少三类；GUI 与 CLI 共用 `internal/policy`，第 4 阶段强化）
- [x] 连续失败锁定 + 指数退避（第 3 次起 2 秒翻倍、上限 60 秒；退避期间拒绝任何尝试；解锁成功清零，第 4 阶段实现）
- [x] 闲置超时自动锁定（默认 5 分钟，可配置项预留，第 4 阶段实现）
- [x] 主密码不以任何形式落盘（内存中派生后即清零）

### 数据保密性与完整性
- [x] 全库 SM4-GCM 加密存储，密钥由主密码派生
- [x] 认证标签校验：任何篡改导致拒绝打开
- [ ] （可选）SM2 对库文件签名，支撑更高等级完整性要求

### 安全审计
- [x] 本地审计日志记录：创建保险箱、解锁（含失败）、新增、复制密码、移入回收站、恢复、彻底删除、备份、恢复备份、锁定（JSONL 追加，不记录密码明文/凭据内容，第 4 阶段实现）
- [ ] 审计日志加密存储（可选 SM3 摘要链防篡改，待定）

### 数据备份与恢复
- [x] 加密备份导出：库文件整体密文副本 + 备份信封（魔数 PVLB/版本/长度/SM3 摘要），恢复时先校验完整性（第 4 阶段实现）
- [x] 恢复流程校验文件头与 SM3 摘要及库格式，任何一步失败即中止且不触碰当前库
- [ ] 备份文件加密钥（可选：备份内容二次加密，待定）

### 剩余信息保护
- [x] 删除为两级：移入回收站（软删除、可恢复）；彻底删除时先以随机数据覆盖旧库文件密文区，再原子写入新库（`storage.ReplaceWithCover`，第 4 阶段实现）
- [x] 主密钥与派生中间值使用后清零（CLI/GUI 服务层）
- [x] 剪贴板中的密码定时自动清除（复制后 30 秒清空，第 3 阶段已实现）

### 密码法 / 商用密码应用（GB/T 39786-2021）
- [x] 仅使用 SM2/SM3/SM4 合规商用密码算法
- [x] 未自行实现或自由组合算法；算法实现来自经过验证的库（emmansun/gmsm）
- [x] 密码应用方案文档化（本仓库 `docs/design.md`），可支撑商用密码应用安全性评估
